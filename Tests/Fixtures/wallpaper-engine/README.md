# Wallpaper Engine test fixtures

Hand-written `project.json` files that follow the shape of real Wallpaper Engine items
(see the sources in `docs/wallpaper-engine-scene-feasibility.md`). Media files here are
**placeholders** (a line of text), not real wallpapers: the scanner only checks that files exist.

- `workshop/content/431960/` mirrors Steam's workshop layout (numeric folder per item).
- `myprojects/` mirrors `wallpaper_engine/projects/myprojects` (named folders, often no workshop id).
